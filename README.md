# inventory-sync
轻量级库存管理系统：客户端+云端同步、Excel 存储、权限分级、历史版本回溯、内网穿透。A lightweight, Excel-based inventory management system with client-server sync, role-based access control, and version rollback. Python (FastAPI) + native HTML/JS. Built with Python (FastAPI) + native frontend, supports intranet tunneling for remote access.
